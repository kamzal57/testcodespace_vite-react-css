# Vite + React + TypeScript Application

A modern, fully-featured React application built with Vite, TypeScript, and CSS modules. This project demonstrates best practices for modern React development with a beautiful, responsive UI.

![Application Screenshot](https://github.com/user-attachments/assets/3d054fa5-e246-402b-b144-5d845836fdeb)

## ✨ Features

- **⚛️ Modern React 18** with TypeScript support
- **⚡ Vite** for lightning-fast development and building
- **🎨 Beautiful UI Components** with custom CSS and animations
- **📱 Responsive Design** that works on all devices
- **🔥 Hot Module Replacement (HMR)** for instant updates
- **✅ ESLint** configuration for code quality
- **🧩 Component Architecture** with reusable components

## 🚀 Getting Started

### Prerequisites

- Node.js 16.x or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd testcodespace_vite-react-css
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 📦 Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint to check code quality
