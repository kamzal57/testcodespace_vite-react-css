# testcodespace_vite-react-css

## Création rapide

1. `npm create vite@latest . -- --template react`
2. `npm install`

## Démarrage & finalisation

- Dev : `npm run dev`
- Build : `npm run build`
- Prévisualisation : `npm run preview`

> Nettoyez ensuite `src/App.jsx` et `src/App.css` pour livrer la version finale.e_vite-react-css
